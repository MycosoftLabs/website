MYCOSOFT ITDX26 — START HERE

1. Extract ALL files from the ZIP into a normal folder.
2. Open the extracted Mycosoft_ITDX26 folder.
3. Start the launcher for your computer:
   Windows: START_HERE_WINDOWS.bat
   Mac:     START_HERE_MAC.command
   Linux:   bash START_HERE_LINUX.sh
4. Wait for APP IS READY. The launcher opens your regular browser.
5. Keep the terminal open while you use the app.

If Python is missing, follow the official installer opened by the launcher,
then run the launcher again. The Windows launcher first tries WinGet.

If something fails: the terminal error and local_data/startup.log show why.
Do not keep refreshing the previous in-app localhost tab; that tab does not
reach a server running in a separate ChatGPT execution environment.

Python diagnostics: python launch.py --diagnose
Startup self-check: python launch.py --smoke-test --no-install

The 4 tasks, 30 documents, 41 scenarios, original modules and evidence exports
remain in this package. See README.md and VALIDATION.md for scope and limits.
